# TrackCapture 数据删除

TrackCapture 无需注册，也没有服务器，因此 Matelog 不保存任何用户数据。所有数据仅保存在您的设备上。

## 删除单条记录
在应用中：**历史** 标签 → 打开记录 → 删除

## 删除全部应用数据
- iPhone：长按应用图标 → 移除 App → 删除 App
- Android：设置 → 应用 → TrackCapture → 存储 → 清除数据（或卸载）

## 保存到相册的结果
本应用保存到相册的照片和视频在删除应用后仍会保留，请在相册中自行删除。

## 已分享的内容
分享到其他服务（如 Instagram）的内容，请在相应服务中删除。
