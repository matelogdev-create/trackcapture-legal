# TrackCapture データ削除

TrackCapture には会員登録もサーバーもないため、Matelog が保管している利用者データはありません。すべてのデータはお使いの端末内にのみ存在します。

## 記録を 1 件削除する
アプリで：**履歴** タブ → 記録を開く → 削除

## アプリのデータをすべて削除する
- iPhone：アプリのアイコンを長押し → App を削除 → App を削除
- Android：設定 → アプリ → TrackCapture → ストレージ → データを削除（またはアンインストール）

## 写真ライブラリに保存した結果
本アプリが写真ライブラリ（ギャラリー）に保存した写真・動画は、アプリを削除しても残ります。写真アプリから削除してください。

## 共有したコンテンツ
他のサービス（Instagram など）に共有したコンテンツは、各サービスで削除してください。
