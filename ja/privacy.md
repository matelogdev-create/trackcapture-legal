# TrackCapture プライバシーポリシー

Matelog（메이트로그、以下「当社」）は、韓国の個人情報保護法および位置情報の保護及び利用等に関する法律に従い、モバイルアプリ **TrackCapture**（以下「本アプリ」）を運営しています。本ポリシーでは、本アプリがどのような情報をどのように扱うかを説明します。

**要約：** 本アプリには会員登録も当社のサーバーもありません。運動記録、位置、写真・動画は**お使いの端末内にのみ保存**され、当社に送信されることはありません。

## 1. 取り扱う情報と目的

| 情報 | 目的 | 保存場所 |
|---|---|---|
| 位置情報（GPS 座標・標高・時刻） | 運動ルートの記録、距離・ペース・速度の計算、写真・動画へのルート表示 | お使いの端末 |
| 写真・動画 | アプリ内カメラでの撮影、選択した写真・動画への記録の合成 | お使いの端末（写真ライブラリ） |
| ヘルスケアアプリの運動記録（Apple ヘルスケア、Health Connect） | 選択した運動のルート・距離・時間の取り込み | お使いの端末 |
| GPX ファイル | 選択したルートファイルの取り込み | お使いの端末 |
| アプリ設定（言語・単位・テンプレートなど） | アプリの動作 | お使いの端末 |

当社は氏名、連絡先、アカウント、広告識別子など、利用者を特定できる情報を収集しません。本アプリには分析・広告・クラッシュレポートのツールは含まれていません。

## 2. アクセス権限

| 権限 | 必須かどうか | 用途 |
|---|---|---|
| 位置情報（アプリ使用中） | 記録機能に必要 | 運動中のルート記録。「常に許可」は求めません |
| カメラ | 撮影機能に必要 | アプリ内での写真・動画の撮影 |
| 写真・動画 | 任意 | 結果の保存、写真・動画の選択 |
| 通知 | 任意 | 記録中の状態表示（Android の常駐通知） |
| ヘルスケアデータ（読み取り） | 任意 | ウォッチの運動記録の取り込み。ヘルスケアアプリへの書き込みは行いません |

任意の権限を許可しなくても、その機能以外はすべて利用できます。権限は端末の設定からいつでも変更できます。

## 3. 保存期間と削除

データは、アプリで記録を削除するかアプリを削除するまで端末内に残ります。アプリを削除すると、アプリが保存したデータはすべて削除されます。写真ライブラリに保存した結果は、写真アプリから削除してください。当社はデータを保管しないため、当社が削除するデータはありません。

## 4. 第三者提供と外部サービス

当社は利用者の情報を第三者に提供しません。ただし、次の場合に本アプリは外部サービスと通信します。

- **地図表示：** 地図を表示するため、OpenFreeMap（tiles.openfreemap.org）に地図画像を要求します。表示中の地図の範囲と端末の IP アドレスが同サービスに送信される場合があります。運動記録そのものは送信されません。
- **共有：** Instagram ストーリーズまたは共有をタップすると、選択した写真・動画が選択したアプリ（Instagram など）に渡されます。その後の取り扱いは当該サービスのポリシーに従います。

当社は個人情報の取り扱いを外部に委託していません。

## 5. 位置情報

本アプリは記録中にのみ位置情報を使用し、当社や第三者に送信することはありません。位置情報が端末外に出ないため、当社はその利用・提供の記録を保管していません。位置情報サービスに関する事項は[利用規約](./terms)をご覧ください。

## 6. 利用者の権利

運動記録はアプリ内で閲覧・編集・削除でき、アプリを削除するとすべてのデータが消去されます。[データ削除](./data-deletion)をご覧ください。お問い合わせは下記メールアドレスまでお送りください。速やかに回答いたします。

## 7. 児童

本アプリは個人情報を収集せず、14 歳未満の児童を対象としていません。

## 8. 安全管理措置

データは各 OS のアプリ専用ストレージに保存され、他のアプリからはアクセスできません。当社のサーバーに送信しないため、通信経路での漏えいのおそれはありません。
