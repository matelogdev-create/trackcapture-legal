# 트랙캡처 개인정보처리방침

메이트로그(이하 "회사")는 모바일 앱 **트랙캡처(TrackCapture)**(이하 "앱")를 운영하며, 「개인정보 보호법」 및 「위치정보의 보호 및 이용 등에 관한 법률」을 지킵니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

**핵심 요약**: 앱은 회원가입이 없고 회사 서버가 없습니다. 운동 기록, 위치, 사진·영상은 **이용자 기기 안에만 저장**되며 회사로 전송되지 않습니다.

## 1. 처리하는 정보와 목적

| 정보 | 목적 | 저장 위치 |
|---|---|---|
| 위치정보(GPS 좌표·고도·시각) | 운동 동선 기록, 거리·페이스·속도 계산, 사진·영상에 동선 표시 | 이용자 기기 |
| 사진·영상 | 앱 카메라 촬영, 갤러리에서 고른 사진·영상에 기록 합성 | 이용자 기기(사진 보관함) |
| 건강 앱 운동 기록(Apple 건강, Health Connect) | 이용자가 고른 운동의 경로·거리·시간 가져오기 | 이용자 기기 |
| GPX 파일 | 이용자가 고른 경로 파일 가져오기 | 이용자 기기 |
| 앱 설정(언어·단위·템플릿 등) | 앱 동작 | 이용자 기기 |

회사는 이름, 연락처, 계정, 광고 식별자 등 이용자를 식별할 수 있는 정보를 수집하지 않으며, 분석·광고·오류 수집 도구를 사용하지 않습니다.

## 2. 접근 권한

| 권한 | 필수 여부 | 용도 |
|---|---|---|
| 위치(앱 사용 중) | 기록 기능에 필요 | 운동 중 동선 기록. "항상 허용"은 요청하지 않습니다 |
| 카메라 | 촬영 기능에 필요 | 앱 카메라로 사진·영상 촬영 |
| 사진·영상 | 선택 | 결과물 저장, 갤러리 사진·영상 선택 |
| 알림 | 선택 | 기록 중 상태 표시(Android 상시 알림) |
| 건강 데이터(읽기) | 선택 | 워치 운동 기록 가져오기. 건강 앱에 쓰지 않습니다 |

선택 권한을 허용하지 않아도 해당 기능 외의 기능은 이용할 수 있습니다. 권한은 기기 설정에서 언제든 바꿀 수 있습니다.

## 3. 보유 기간과 파기

정보는 이용자가 앱에서 기록을 지우거나 앱을 삭제할 때까지 기기 안에 남습니다. 앱을 삭제하면 앱이 저장한 정보는 모두 삭제됩니다. 이용자가 사진 보관함에 저장한 결과물은 사진 보관함에서 직접 지워야 합니다. 회사는 정보를 보관하지 않으므로 별도로 파기할 정보가 없습니다.

## 4. 제3자 제공과 외부 서비스

회사는 이용자 정보를 제3자에게 제공하지 않습니다. 다만 앱 기능상 다음과 같은 외부 통신이 있습니다.

- **지도 표시**: 지도를 그리기 위해 OpenFreeMap(tiles.openfreemap.org)에 지도 이미지를 요청합니다. 이때 보고 있는 지도 영역과 기기의 IP 주소가 해당 서비스에 전달될 수 있습니다. 운동 기록 자체는 전송되지 않습니다.
- **공유**: 이용자가 [인스타 스토리]나 [공유]를 누르면, 이용자가 고른 사진·영상이 이용자가 선택한 앱(인스타그램 등)으로 전달됩니다. 이후 처리는 해당 서비스의 방침을 따릅니다.

회사는 개인정보 처리를 위탁하지 않습니다.

## 5. 위치정보

앱은 기록 중에만 위치정보를 사용하며, 위치정보를 회사나 제3자에게 전송하지 않습니다. 위치정보 이용·제공 사실 확인자료는 기기 밖으로 수집되지 않으므로 회사가 보관하지 않습니다. 위치기반서비스에 관한 사항은 [이용약관](./terms)을 따릅니다.

## 6. 이용자의 권리

이용자는 앱 안에서 기록을 직접 조회·수정·삭제할 수 있고, 앱 삭제로 모든 정보를 지울 수 있습니다. 데이터 삭제 방법은 [데이터 삭제 안내](./data-deletion)를 참고해 주세요. 문의는 아래 연락처로 보내 주시면 지체 없이 답변하겠습니다.

## 7. 아동의 개인정보

앱은 개인정보를 수집하지 않으며, 만 14세 미만 아동을 대상으로 하지 않습니다.

## 8. 안전성 확보 조치

정보는 각 운영체제의 앱 전용 저장 공간에 저장되어 다른 앱이 접근할 수 없습니다. 회사 서버로 전송하지 않으므로 전송 구간의 유출 위험이 없습니다.
