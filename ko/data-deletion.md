# 트랙캡처 데이터 삭제 안내

트랙캡처는 회원가입과 서버가 없어서, 회사(메이트로그)가 보관하는 이용자 데이터가 없습니다. 모든 데이터는 이용자 기기 안에만 있습니다.

## 기록 하나 지우기
앱의 **내역** 탭 → 기록 선택 → 삭제

## 앱 데이터 전부 지우기
- iPhone: 홈 화면에서 앱 아이콘을 길게 누름 → 앱 제거 → 앱 삭제
- Android: 설정 → 애플리케이션 → 트랙캡처 → 저장공간 → 데이터 삭제 (또는 앱 제거)

## 사진 보관함에 저장한 결과물
앱이 사진 보관함(갤러리)에 저장한 사진·영상은 앱을 지워도 남습니다. 사진 앱에서 직접 삭제해 주세요.

## 공유한 콘텐츠
인스타그램 등 다른 서비스에 공유한 콘텐츠는 해당 서비스에서 삭제해 주세요.
